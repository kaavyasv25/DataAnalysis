# Data Analysis Portfolio

## Overview

This repository comprises a collection of data analysis projects, each focusing on different datasets and analytical techniques. The projects are organized into individual directories, each containing the necessary code, data, and documentation.

## Projects

### 1. Adult Income EDA

**Directory:** `AdultIncomeEDA`

**Description:** This project involves exploratory data analysis (EDA) on the Adult Income dataset to understand the factors influencing income levels.

**Contents:**
- Data preprocessing and cleaning scripts.
- Jupyter Notebooks detailing the EDA process.
- Visualizations illustrating key insights.

### 2. NYC Real Estate Analysis

**Directory:** `NYCRealEstate`

**Description:** An analysis of New York City's real estate market, focusing on property sales data to identify trends and patterns.

**Contents:**
- Data collection and cleaning scripts.
- Jupyter Notebooks with analysis and visualizations.
- Summary of findings and conclusions.

### 3. Superstore Sales Analysis

**Directory:** `Superstore`

**Description:** A comprehensive analysis of sales data from a fictional superstore, aiming to uncover insights into sales performance and customer behavior.

**Contents:**
- Data preprocessing scripts.
- Jupyter Notebooks with detailed analysis.
- Visualizations highlighting sales trends and customer demographics.
